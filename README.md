
# Stone – Paper – Scissors Game 🎮

This is a **console-based Stone – Paper – Scissors game** implemented in **C++**.  
The game allows the player to compete against the computer in multiple rounds, and at the end, it displays the overall winner.  

---

## 🔹 Features
- Player chooses the number of rounds (1–10).
- Computer makes a random choice each round.
- Displays the winner of each round.
- Shows a summary with:
  - Total rounds played
  - Player win times
  - Computer win times
  - Draw times
  - Final winner
- Console colors change based on the round/game result (Green → Player, Red → Computer, Yellow → Draw).
- Option to play again after the game ends.

---

## 🔹 Technologies & Concepts Used
- **C++**
- **Enums** → For player/computer choices and winners.
- **Structs** → To store round info and game results.
- **Functions** → For modular and organized code (e.g., read choice, check winner, print results).
- **Random Number Generation** → To simulate the computer’s moves.
- **Loops & Conditions** → For game flow control.
- **System Commands** → `cls` to clear console, `color` to change console color.

---

## 🔹 Learning Goals
- Practice structuring code with **structs** and **functions**.
- Understand the use of **enum** and **switch-case**.
- Implement simple **game logic** with randomization.
- Strengthen knowledge of **C++ basics**.
